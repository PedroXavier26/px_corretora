# 🏢 Site Institucional – Consultoria e Corretagem de Seguros

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um site institucional para uma empresa de consultoria e corretagem de seguros, com foco em transmitir profissionalismo, credibilidade e fortalecer a presença digital da marca.

O site foi estruturado com abordagem corporativa, priorizando clareza das informações, organização visual e facilidade de navegação para potenciais clientes.

---

## 🚀 Funcionalidades

- Página institucional com apresentação da empresa  
- Seção detalhada de serviços oferecidos  
- Área de contato para comunicação direta  
- Layout corporativo  
- Design responsivo  
- Navegação intuitiva  

---

## 🎯 Objetivo

O principal objetivo deste projeto foi:

- Aplicar conceitos de design institucional  
- Desenvolver um projeto voltado para cliente real  
- Trabalhar comunicação visual corporativa  
- Praticar organização estrutural de um site empresarial  
- Reforçar boas práticas de desenvolvimento front-end
